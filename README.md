# 头歌课程实验工具（抓取 · AI 作答 · 自动提交）

把头歌（educoder.net）课程实验的题目抓成本地存档，用 **AI 或平台标准答案**生成答案库，
再由**篡改猴脚本**在关卡页自动作答、点「评测」、判通过后进入下一关。

三个组件各管一段：

| 组件 | 形态 | 职责 |
| --- | --- | --- |
| **extractor** | Node + Playwright（`npm run extract` / `npm run ui`） | 登录一次，把课程 → 课堂实验 → 关卡的题目正文、选项、初始代码、图片抓成本地存档 |
| **本地控制台** | `npm run ui`（只监听 127.0.0.1） | 驱动抓取；聚合答案库（AI 作答 / 平台标准答案回传）；给篡改猴提供答案、关卡映射、选项个数 |
| **篡改猴脚本** | Tampermonkey 用户脚本 | 在关卡页自动填答案、点「评测」、等结论、进下一关；支持教学课程队列批量推进 |

> **免责声明**：本工具只用于个人学习、备份自己有权限访问的课程内容。
> 自动作答与提交可能违反平台条款，使用风险自负；请勿用于刷课代做等用途。

## 快速上手

### 1. 安装

```powershell
npm install        # 依赖：playwright（Node 22，CommonJS）
npm run ui         # 启动本地控制台（自动开浏览器，终端打印带 token 的地址）
```

### 2. 登录一次

控制台里点「开始提取」会开一个独立 Chromium，在里面完成头歌登录。登录态存本地
`.educoder-browser/`，之后**不用每次重新登录**。

### 3. 抓题

控制台选 课程 → 实验 → 关卡，点「开始提取」。产物：

```text
exports/
├── answers/                                 ★ 答案库（AI 产出 + 平台标准答案回传）
│   └── 软件工程导论2026年下半年__单元测试.answers.json
├── logs/                                    ★ 篡改猴脚本回传的运行日志
└── 软件工程导论2026年下半年/
    └── 单元测试/
        ├── levels.jsonl                     # 关卡存档（唯一事实来源，每关一行）
        ├── 单元测试.md                      # AI 友好的题目正文（含每关「作答格式」）
        ├── 单元测试.metadata.json
        └── assets/L001-image-1.png
```

**只保留编程题与选择题**：虚拟机/图形化实操题（Logisim、StarUML、VNC 等）没有可
自动作答的环境，一律跳过并说明原因。

## 签名常量（AK/SK）：是什么、怎么配

**这个项目必须配置它**——抓取和篡改猴脚本的课程/关卡读取，走的是头歌自己的 API，
每个请求都要带三个签名头：

```text
X-EDU-Timestamp: <毫秒时间戳>
X-EDU-Signature: md5(base64("method=GET&ak=<AK>&sk=<SK>&time=<同一个时间戳>"))
X-EDU-Type:      pc          ← 必须精确是 pc，写成 web 会被拒
```

- **AK（Access Key）/ SK（Secret Key）是什么**：拼进签名串的两个常量。服务端用同样的
  常量重算一遍签名，对得上才放行——相当于「证明这个请求来自头歌自己的前端」。
- **它们不是你的账号密码**：是头歌**前端 JS 里写死的公开常量**，所有用户同一对，
  从公开 CDN 的 `umi.<hash>.js` 里就能搜到（搜 `setHeader` / `getKey`）。
- 你的**账号凭据在 Cookie**（`_educoder_session`）里，与 AK/SK 无关。一个请求要成功 =
  正确的签名（靠 AK/SK）+ 有效的登录态（靠 Cookie）。
- **最容易踩的坑**：缺头或算错签名时，接口报的是
  `-102「服务器时间与您的设备时间不匹配」`——**这是误导信息，跟系统时间无关**。

### 怎么配置（两个入口都要）

| 入口 | 方式 |
| --- | --- |
| **extractor / 控制台**（Node 侧） | 在仓库根建 `.educoder-keys.json`（已 gitignore）：`{ "ak": "<双 base64>", "sk": "<双 base64>" }`；或设环境变量 `EDUCODER_AK` / `EDUCODER_SK` |
| **篡改猴脚本**（浏览器侧） | 菜单「**设置签名常量（首次使用）**」→ 粘贴 AK、SK 各一次。存 GM 存储（浏览器本地），脚本更新不丢 |

**获取方式**：浏览器打开任意头歌页面 → 开发者工具 → Sources/Network 找
`www-cdn.educoder.net/umi.<hash>.js` → 搜 `setHeader` / `getKey` → 两个双 base64 串。

**失效怎么办**：网站改版会换掉这对常量，届时所有请求重新报 `-102`。重新抓一遍
`umi.<hash>.js`，更新 `.educoder-keys.json`（或重新粘贴到菜单）即可。常量变更日期见
`extractor/lib/educoder-sign.js` 里的 `SIGNING_VERSION`。

## 答案从哪来：两条路

### 路 A：AI 生成

控制台「AI 作答」面板：选课程/实验/关卡 → 填模型接口、模型名、API Key → 开始。
逐实验把 `实验.md` 交给 OpenAI 兼容的 `/chat/completions`（默认
`https://api.deepseek.com/v1` + `deepseek-chat`，任何兼容接口都行），答案写到
`exports/answers/{课程}__{实验}.answers.json`，并立刻自校验（覆盖度、题型、
选项字母越界、占位代码）。API Key 只存在控制台进程内存里，不落盘不进日志。

### 路 B：平台标准答案回传（更可靠）

**提交过一关之后**，平台的关卡数据里就有这一关的 `standard_answer`。篡改猴脚本可以：

- 「导出标准答案（本实验全部）」：从当前关沿关卡链逐关拉取，把整条链的标准答案一次回传；
- 每关通过后也会自动回传当关答案。

平台的标准答案是**按关卡**给的、且**只有提交过才有**；纯编程题没有标准答案
（平台不吐标准代码），这类只能靠 AI 或人工。

### 缺答案清单

教学课程队列跑到「没有本地答案」的关卡时，会把关卡名记入缺答案清单并上报控制台
（`/api/missing`），跑完后按清单补答案即可，不会卡住队列。

## AI 答题：开发进度

> **作者没有测试过 AI 答题功能。** 下面这张表只说明「代码写到了哪一步」，不代表
> 「实测有效」——从模型出答案到篡改猴提交，这条链路作者本人一次都没真正跑过，
> 效果未经实际验证。作者自己准备用 ZCode + GLM 5.3 补上第一轮实测（写这段时它正免费）。

如实标注，不吹。

| 环节 | 状态 | 说明 |
| --- | --- | --- |
| 题目抓取（关卡存档 + AI 友好 md） | ✅ 完成 | `levels.jsonl` 单一事实来源；图片落 `assets/`；内容指纹去重；子标签实验支持 |
| AI 生成答案（OpenAI 兼容接口） | ✅ 完成 | 控制台「AI 作答」面板；答案自校验；`unanswered` 明细 |
| 答案库与关卡映射 | ✅ 完成 | `level_id` ↔ 平台标识；含「实验名__关卡名」「关卡名」两级兜底（平台换标识也能对上） |
| 篡改猴自动作答与提交 | ✅ 完成 | 选择题按分组勾选 / monaco 写入；点页面「评测」；**判通过才进下一关** |
| 教学课程队列（多实验多关卡） | ✅ 完成 | 存档续跑、跳过已通过、缺答案清单、日志落盘、卡住自检 |
| 平台标准答案回传 | ✅ 完成 | 单关 / 整实验批量；未提交过或纯编程题会明确列出 |
| 答案格式校验 | ✅ 完成 | `node tools/validate-answers.js`：覆盖度/题型/选项字母/占位代码 |
| **AI 答案的内容正确性** | ⚠️ 无保证 | 格式对了不代表能过评测——编程题可能跑不过，队列会停在那一关等你修 |
| **端到端全自动无人值守** | ⚠️ 受平台限制 | 评测不通过/超时会停队列（故意设计）；虚拟机与图形化题不参与；纯编程题无标准答案可回传 |
| 图片题理解 | ❌ 未做 | 图片会下载并嵌进 md，但发给模型的只有文本和路径，模型看不懂图 |
| 评测等待 | ✅ 完成 | 上限取页面声明的「最大测评时间」（读不到才退回面板设置）；0.5s 轮询，出结论立刻走 |

**一句话**：抓题、出答案、自动提交这条链是通的；瓶颈在**答案质量**——
最省力的实际用法是「AI 先答 → 通过的关卡自动回传标准答案 → 没过的关卡用标准答案重跑」。

## 篡改猴脚本

| 步骤 | 操作 |
| --- | --- |
| 1 | 装 Tampermonkey，新建脚本粘贴 [userscript/educoder-autosubmit.user.js](userscript/educoder-autosubmit.user.js) |
| 2 | 菜单「**设置签名常量（首次使用）**」粘贴 AK/SK（见上文） |
| 3 | 打开控制台 → 复制带 token 的地址 → 脚本面板「设置本地地址」粘贴 → 「从本地拉答案」 |
| 4 | 面板「教学课程」区：刷新课程 → 读取课程实验 → 勾选实验/关卡 → 一键答题（选中） |

**面板按钮**：`一键作答并提交`（单关）｜`停止`（两条流程都停）｜`从本地拉答案`｜
`设置本地地址`｜`导出本实验全部答案`｜教学课程区（队列）｜`导出日志到本地`（落到
`exports/logs/`，队列跑完/停下会自动传一次）。

**队列特性**：判通过才进下一关（可关）；停在哪、下次点「继续答题（跳过已通过）」
就从哪继续；缺答案的关卡跳过并记账；点了「下一关」页面没跳转会重试并明确停队列。

**安全默认**：只有明确的「通过」才往下走；选择题页面题数与答案题数不一致就整体放弃；
提交优先点页面自己的「评测」按钮，找不到才重放录制到的接口。

## 输出结构

见[快速上手第 3 步](#3-抓题)。要点：

- **存档与视图分离**：抓取只往 `levels.jsonl` 追加；`实验.md` / `.metadata.json` 是
  视图，可随时 `node tools/build-exports.js` 重建。
- 同一关重抓追加新行，读取时最后一行生效；题目内容变了（指纹不同）只重写那一关。
- 答案集中在 `exports/answers/`，命名 `{课程}__{实验}.answers.json`；格式规范见
  [docs/AI-ANSWER-FORMAT.md](docs/AI-ANSWER-FORMAT.md)，存储设计见
  [docs/STORAGE.md](docs/STORAGE.md)。

## 排查问题

| 症状 | 多半是 | 处置 |
| --- | --- | --- |
| 接口报 `-102 服务器时间不匹配` | **缺签名头或常量失效**（与系统时间无关） | 检查签名常量配置；网站改版则更新常量 |
| 答案拉到了但「没有本地答案」 | 关卡标识对不上 / 实验没抓过 | 看日志里的「关卡上下文」；重新抓该实验 |
| 「页面上找不到代码编辑器（等了 8 秒…现场：…）」 | Monaco 异步挂载没等到，或真没有 | 把括号里的现场发出来看：`monaco 模型 0 个` = 还没挂载/真没有 |
| 队列停在「评测超时」 | 评测跑得比等待上限久 | 调大面板「评测最多等（秒）」；已通过的关卡重跑会自动跳过 |
| 面板日志被清空看不清 | 落盘后自动清空（保留最后 5 行） | 看本地 `exports/logs/篡改猴日志.log`，那是全量 |
