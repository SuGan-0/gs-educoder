# 纯脚本使用文档（不用本地控制台）

> 只用**篡改猴脚本**，不启动本地控制台、不跑抓取。
> 适合：拿一份现成的答案文件直接跑，或把答案分发给同学。
>
> **脚本本身不需要 Node 环境**（装个浏览器扩展就能用）。只有「自己生成答案文件」这一步
> 才用到仓库里的命令——答案也可以直接从控制台导出、或由同学传给你。
>
> 想抓题、让 AI 作答、管理答案库 → 用完整链路，见 [README](../README.md)。
> 连控制台与不连控制台**不是两个版本**，脚本是同一个，「连接本地控制台」是可选项。

---

## 一、你需要准备什么

| 要的东西 | 从哪来 | 是否必须 |
| --- | --- | --- |
| Tampermonkey 扩展 | 浏览器扩展商店 | 必须 |
| `userscript/educoder-autosubmit.user.js` | 本仓库 | 必须 |
| **一份班级答案文件**（`*.answers.json`） | ① 本仓库里已经有：`exports/answers/{年级}-{班级}.answers.json`；② 跑 `npm run build-class-answers` 重新生成一份；③ 控制台「导出班级答案文件」；④ 同学传给你 | 必须（没有答案也能跑，只是每关都会跳过） |
| 签名常量 AK / SK | **首次使用粘一次**：菜单「设置签名常量」→ 粘贴 AK、SK（双 base64）。仓库里的脚本**不带真实常量**，值存在篡改猴本地存储 | 粘一次 |

## 二、装脚本

1. 装 **Tampermonkey**。
2. 新建脚本，把 `userscript/educoder-autosubmit.user.js` **整个文件**粘进去，保存。
3. 打开任意 `https://www.educoder.net/` 页面，左下角会出现面板。

> 脚本更新后要**重新粘贴一次**（脚本存储里的答案与设置不会丢）。

---

## 三、第一次配置（两件事：粘常量 + 导入答案）

### 1. 签名常量：粘一次

菜单 **「设置签名常量」** → 分别粘贴 AK、SK。粘完存进篡改猴的脚本存储，**以后不用再粘**
（脚本更新也不丢）。

- 这套常量是头歌前端 JS 里写死的**公开客户端常量**（不是你的账号密码，所有用户同一对）。
  仓库里的脚本**不带真实值**，所以第一次要自己粘一次。
- 平台换常量、接口开始报 `-102` 时：同样走菜单粘新值（GM 存储优先）。
- 粘错会被**当场拦住**并说明原因，不会存下来。最常见的错法是只粘了「解过一次」的那串——
  要粘的是**双 base64**（更长、以 `=` 结尾）。

### 2. 把答案装进来

面板按钮 **「从本地加答案」**（或菜单同名项）：

| 情况 | 会怎样 |
| --- | --- |
| 配了控制台地址且连得上 | 从控制台拉 |
| 没配地址 | **直接弹文件框**，选一份班级答案文件导入 |
| 配了但连不上 | 报一句原因后，**自动退到选文件导入** |

也可以直接用菜单 **「导入答案文件（班级答案文件 / 控制台响应）」**，它认两种格式：

| 文件 | 说明 |
| --- | --- |
| **班级答案文件**（`kind: "class-answers"`） | 纯脚本模式的**首选** |
| 控制台 `/api/answers` 的响应 | 带 `levelIds` / `optionCounts` / 蓝图，信息最全 |

导入成功会打印：

```text
班级答案文件已导入（xxx.answers.json）：2024级软工24-15、16班｜155 关（有答案 102），关卡标识映射 155 条、唯一关卡名 147 个
现在共 155 关答案，可以不连本地控制台直接答题
```

导入是**合并**：不同关卡会累加，同一关以**导入文件里的那份**为准。

### 3. 核对

菜单 **「状态总览」**，应看到：

```text
状态总览：答案 155 关｜关卡映射 155 条｜页面关卡数据✗｜控制台选项数✗｜签名常量✓｜提交蓝图 0 个
```

逐项含义：

| 项 | 期望 | 说明 |
| --- | --- | --- |
| 答案 N 关 | 越大越好 | 你库里有多少关答案 |
| 关卡映射 M 条 | 与答案数**接近** | 没有它，答案是按 `L001` 存的、页面按 URL 上的标识查，两边对不上 |
| 页面关卡数据 | 关卡页上是 `✓` | 「每题几个选项」的最权威来源，**由页面自己提供**；不在关卡页时是 `✗`，正常 |
| 控制台选项数 | `✗` 正常 | 不连控制台就没有，不影响答题 |
| **签名常量** | 必须 `✓` | `✗` 时读课程/实验/关卡会失败 |
| 提交蓝图 | `0` 也能跑 | 只在「页面上找不到提交按钮」时才需要重放接口；手动提交一次就会自动录到 |

## 四、日常使用：四步

面板是一条**顺序流水线**，同一时刻只有一步是活的，步骤条（① 课程 ── ② 实验 ── ③ 关卡）可点回去改。

```text
① 课程：选课程 →「刷新课程」→「读取课程实验 →」
② 实验：勾选要做的实验 →「读取关卡 →」
        （这一步读完**一定停在②**，不会跳过去）
③ 关卡：勾选要做的关卡（默认全选）
        →「一键答题（选中）」
```

**「一键答题（选中）」会做什么**：从选中的第一个实验开始，逐关填答案 → 点页面自己的「评测」→
**判定通过才进下一关**；通过的关卡自动跳过；**通过的关卡还会把答案收进本地答案库**
（日志会写「这一关的答案已存进本地答案库」）；跑完整个实验自动进下一个。

跑起来后按钮会变：停下后同一个按钮显示 **「继续答题（跳过已通过）」**，再点就是从停下那关接着跑。

## 五、面板说明

```text
标题栏（可拖动 / 右侧「收起 ▴」收起整个面板）
步骤条：① 课程 ── ② 实验 ── ③ 关卡
[当前这一步的内容]
一键答题（选中）│ 停止 │ 按清单再答
连接本地控制台 │ 从本地加答案 │ 导出本实验全部答案 │ 导出全部答案 │ 导出日志到本地
评测最多等（秒，页面读不到才用）
关卡数据最多等（秒）
日志                      ← 可拖动下边缘调高度
```

| 按钮 | 作用 | 纯脚本模式 |
| --- | --- | --- |
| **一键答题（选中）** | 跑队列，见上 | ✅ |
| **停止** | 当前这一关做完就停 | ✅ |
| **按清单再答** | 按「缺答案清单」逐关直达 | ⚠️ **需要控制台**（清单存在控制台侧数据库） |
| **连接本地控制台** | 粘控制台地址+token | 可选 |
| **从本地加答案** | 拉 / 导入答案 | ✅ |
| **导出本实验全部答案** | 回捞平台标准答案并**叠加进答案库**，见第六节 | ✅ |
| **导出全部答案** | 把答案库**下载**成文件 | ✅ |
| **导出日志到本地** | 日志写进 `exports/logs/` | ⚠️ 需要控制台；纯脚本模式下日志只在面板里 |

### 两个设置项

| 设置 | 默认 | 什么时候改 |
| --- | --- | --- |
| **评测最多等（秒，页面读不到才用）** | 30 | 页面标了「最大测评时间」时脚本优先用页面的；这一项只在读不到时才生效 |
| **关卡数据最多等（秒）** | 60 | 页面加载慢就调大。**请求失败**的情况不用调大——那种情况脚本 5 秒就转去刷新重试 |

### 日志

- 只留在面板（存浏览器本地），**上限 300 条**：始终保留**最新的 300 条**，超出的从头删（启动时也会先裁一遍，防止旧版本攒下的超量日志一直挂着）。
- 「导出日志到本地」需要控制台；纯脚本模式下用面板的日志区看即可，它**可拖动下边缘调大**。

## 六、导出与导入（两个导出入口分工不同）

| 入口 | 做什么 | 产出 |
| --- | --- | --- |
| **导出本实验全部答案** | 沿关卡链逐关拉取：**选择题**收平台标准答案（提交过才有）、**编程题**收「已通过」关卡的仓库代码，**写进答案库（覆盖已有答案）** | **不下载文件**。按钮上会闪「✓ 已写入 N 关」，日志给一句总结 |
| **导出全部答案** | 把答案库整份导出成班级答案文件 | **下载一份 `.json`**，与「导入答案文件」**同一格式，可原样导回** |

> 编程题的答案来源说明：平台对编程题**没有 standard_answer**；但「已通过测评」的关卡，
> 代码仓库里那份文件就是平台收下的答案（与提取器同款来源）。未提交/未通过的编程题
> 仓库里只有题目模板，**不会**被当成答案收进来（收了模板，作答时填的全是模板）。

典型用法：

```text
跑队列（通过的关卡会自动把标准答案回传进答案库）
   ↓
想补齐剩下的 → 「导出本实验全部答案」（写进库里：已有答案的会被平台标准答案覆盖）
   ↓
想备份 / 换机器 / 传同学 → 「导出全部答案」→ 得到 .json → 在别处「导入答案文件」
```

### 「导出本实验全部答案」的结果提示

点完**一定会有反馈**，不会静默结束：

- **按钮**：临时变成 `✓ 已写入 N 关`（绿）、`⚠ 拉到了但没写入`（黄）或 `✗ 没拉到答案 / ✗ 不是关卡页`（红），几秒后还原。面板收起时也看得见。
- **日志**：一句总结，形如
  `导出「实验名」成功：拉到 12 关标准答案，已写入 12 关（覆盖 9 关、新补 3 关），答案库现在共 155 关`。

### 覆盖规则（重要）

回捞到的答案（选择题标准答案 / 已通过编程题的代码）是**覆盖**，不是「已有就跳过」——它就是判分依据，比导入来的那份权威。

两个例外（一个条目只能存一种答案，覆盖会把另一种弄丢）：

- **库里这一关已经是代码答案**，回捞到的是选择题标准答案 → 保留代码；
- **库里这一关已经是选择题答案**，回捞到的是代码 → 保留选择题。
这种情况日志会写「N 关…保留…没覆盖」。

另外，**没写进去**的两种情况也会分别说明：

- 库里没有这一关的条目（这个实验没导入过答案）→ 提示先「从本地加答案」导入班级答案文件；
- 这一关没提交过/未通过（选择题没标准答案、编程题仓库里只有模板）→ 列在「N 关没有可导出的答案」里。

### 数据安全的三条硬规则

1. **草稿与模板不算答案**：整条链一关都拉不到时的兜底——选择题只认页面提交后的平台标准答案；
   编程题只认「**已通过测评**」的关卡（此时编辑器里那份就是平台收下的答案），
   未通过的编程题编辑器/仓库里的内容不写入。
2. **回捞接口带作业号**（`homework_common_id`）：一个实训挂多个作业的课程（如软件工程导论），
   序号按作业内算，关卡号（L###）不会错位。
3. **回传控制台按真实归属实验**：链条可能跨作业，顺带回捞到的邻实验关卡，
   回传时标的是它真正属于的实验，不会写进错误实验的答案文件。

导出的文件里，每个关卡都会带上**平台关卡标识**（`identifiers`）与班级块，
所以「导出 → 导入」是**往返一致**的（换机器、给同学都不会失真）。

## 七、队列的行为规则

这几条都是硬规则，知道它们就不会被「怎么跳过去了」吓到：

| 情况 | 行为 |
| --- | --- |
| 判定**通过** | 进下一关 |
| 提交**未通过** | **停下**，日志说清是哪一关（这条没有开关） |
| 关卡**已通过** | 跳过（重跑不怕，不会重复交） |
| 这一关**没有本地答案** | 记入缺答案清单 → **跳过** → 继续后面 |
| 答案**残缺**（库里只登记了「是编程题」却没存代码） | 同上：**记入清单并跳过**，不再停整队 |
| 答案**与这一关对不上**（题数不符，多半过期或挂错） | 同上：**记入清单并跳过**，**一个选项框都不会勾** |
| 选择题题数与页面不符 | 整体放弃勾选（安全优先），按上一条跳过 |
| **关卡数据没读到** | 先等（最多「关卡数据最多等」秒，默认 60）→ 仍没有就**刷新页面重试，每关最多 2 次、两次之间至少隔 10 秒**（间隔不能省：请求失败时脚本 5 秒就会早退，不补间隔就成了连着刷，网络抖动反而更容易全失败）→ 都不行才停队 |
| 点了「下一关」页面没动 | 重试一次 → 仍不动就用控件的目标地址直接跳转 |

**一句话**：**单关的问题不会拖垮整条队列**——缺答案、答案过期、题数不符、数据没读到（会先刷新重试）
都会记账后跳过，继续后面。整条队列**只在这些时候停**，并且一定告诉你是哪一关、为什么：

| 停下来的原因（日志原文） | 性质 |
| --- | --- |
| `提交未通过` | 答案不对，得改答案 |
| `评测超时` / `没拿到明确结论` | 评测没给出结论 |
| `没有成功勾选任何题目` | 页面结构不对劲 |
| `页面上找不到代码编辑器` / `页面上找不到提交按钮` | 页面结构不对劲 |
| `等了 N 秒、刷新重试 2 次还是没读到关卡数据` | 这一关打不开 |
| `点了「下一关」但页面没有跳转` | 工具点不动 |
| `当前页面不是队首` | 你手动点到了别的关卡 |
| `用户点了停止` | 你自己停的 |

**停下之后怎么续**：再点「继续答题（跳过已通过）」。已通过的会自动跳，从停下那关继续。
想从头跑：菜单「清空答题进度（下次从头跑）」。

## 八、排查问题（按日志原文找）

| 日志里看到 | 多半是 | 怎么办 |
| --- | --- | --- |
| `签名常量不可用…若平台换过常量导致 -102` | 常量失效（没粘 / 粘错 / 平台换过常量） | 菜单「设置签名常量」粘贴新的**双 base64** 值 |
| `AK/SK 没通过校验：…只粘了「解过一次」的那串` | 粘错了 | 重新粘**双 base64** 那串（更长、以 `=` 结尾） |
| `还没有答案库` | 没导入 | 面板「从本地加答案」 |
| `没有关卡映射` | 导入的文件不带 `levelIds` | 改用**班级答案文件**（`npm run build-class-answers` 生成的那种） |
| `页面自己拉关卡数据（xxx）失败了：Failed to fetch` | 网络抖动 / 被限制，不是慢 | 脚本会自动刷新重试；反复出现就换网络或过一会儿再跑 |
| `等了 N 秒、刷新重试 2 次还是没读到关卡数据` | 页面一直打不开 | 手动确认这一关能不能打开；能打开就再点「继续答题」。**注意：这一关的等待设置只在这条路上生效**——若你看到的是旧文案「页面可能还在加载或被拦」，说明脚本没更新，重新粘贴一次 |
| `点了「查看实战」页面既没跳转、也没能拿到目标地址` | 入口控件改版 / 被遮 | 日志会带当前路径与页面上的按钮；顺便看有没有**多开一个标签页**（队列可能在那边跑） |
| `浏览器不允许脚本关闭这个标签页` | 那页是僵尸页（新标签页接走了队列） | 手动关掉它即可 |
| `评测超时（超过等待上限还没出结果）` | 评测跑得比上限久 | 调大「评测最多等（秒）」；已通过的关卡重跑会自动跳过 |
| `提交未通过` | 答案不对（或平台标准答案被改） | 对着这一关核对答案，改完 `npm run build-class-answers` 重导一次 |
| `答案与这一关对不上` | 答案过期 / 挂错实验 | 用 `npm run check-fit` 在本地提前查；或对该实验「导出本实验全部答案」回捞 |
| `答案里没有代码内容——记入缺答案清单并跳过` | 库里这一关只登记了「是编程题」却没存代码 | **不用管**，脚本会跳过并记账；想把这一关做掉就自己写代码提交一次（通过后会自动入库） |

通用手段：

- 菜单 **「状态总览」** 先看四项状态。
- 日志区**拖大**看全（面板日志只留 300 条）。
- 拿不准就把日志发出来（面板选中即可复制）。

## 九、数据存在哪 / 怎么搬家

| 数据 | 位置 |
| --- | --- |
| 答案库、关卡映射、提交蓝图、班级信息、日志、面板位置、两个设置项 | **浏览器本地脚本存储**（Tampermonkey 管理的 GM 存储） |
| 签名常量 | 同上（键 `educoder-sign-ak` / `educoder-sign-sk`）；存储被清后需要重新粘一次 |

**换机器 / 换浏览器**：先把答案导出来（「导出全部答案」），在新机器上装好脚本 → 导入那份 `.json`。签名常量不用管（内置的会自动补）。

**注意**：答案与设置**不在**网页的 cookie 里，清浏览器数据时如果勾了「网站数据」，
Tampermonkey 的脚本存储可能一起被清 —— 重要答案先导出留档。

## 十、和完整链路的区别

| | 纯脚本 | 完整链路（+ 本地控制台） |
| --- | --- | --- |
