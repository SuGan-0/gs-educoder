# 纯脚本使用：导入答案、作答与粘贴解锁

完整版脚本 **0.5.6** 的代码、选择题和粘贴功能可以不启动本地控制台使用。浏览器需要 Tampermonkey 和答案 JSON；不需要 Node。篡改猴不处理需要操作虚拟机的关卡。
自己抓题、请 Agent 作答或生成班级文件时才使用仓库工具，完整流程见 [README](../README.md)。

只想解除禁止粘贴，可直接安装 [独立粘贴解锁脚本](../userscript/educoder-paste-unlock.user.js)，无需答案或签名常量。
它与 [完整版脚本](../userscript/educoder-autosubmit.user.js) 任选一个安装即可；更新后刷新已打开的实验页。

## 1. 准备与安装

| 准备项 | 说明 |
| --- | --- |
| Tampermonkey | 在浏览器中安装扩展并启用 |
| 完整版脚本 | 新建脚本，粘贴 `userscript/educoder-autosubmit.user.js` 的全部内容并保存 |
| 班级发布文件 | 推荐使用 `exports/answers/{年级}-{班级}.answers.json`，顶层为 `version: 2`、`kind: "class-answers"` |
| 头歌登录态 | 在当前浏览器登录本人账号，确认可以打开目标课堂与实验 |
| 签名常量 AK/SK | 课程和关卡列表读取需要；纯脚本使用时通过篡改猴菜单设置一次 |

签名常量使用当前头歌前端的**双 base64** 值，菜单会校验编码。仓库中的脚本不附真实常量，也不会在清空存储后自动补回。
它们与登录 Cookie 分开：有常量仍需登录，有登录态也不能省去脚本读取课程所需的签名。
仅粘贴解锁不需要 AK/SK。

## 2. 答案文件从哪里来

推荐由抓取器整理本地题目，再交给外部 Agent 按 [作答说明](AGENT-ANSWERING.md) 补全工作答案，校验后生成班级文件：

```powershell
node tools/validate-answers.js "课程名称" "实验名称"
npm run check-fit
npm run build-class-answers -- --grade="2024级" --class="示例班级"
```

也可以在本地控制台的 **导出班级答案** 面板填写年级、班级，点 **导出班级文件**。
面板的 **下载作答说明** 和 **复制 Agent 任务** 用于准备作答上下文。控制台不直接调用模型完成作答。

| 文件类型 | 结构与作用 |
| --- | --- |
| 实验工作答案 | `schema_version: 2`、`classroom`、`experiment`、`answers`；由抓取器或 Agent 写入 |
| 班级发布文件 | `version: 2`、`kind: "class-answers"`、`class`、`classrooms`；汇总后给脚本导入 |

工作答案中，编程题为 `answer: { language, code }`；选择题为 `answer: { questions: [{ number, selected }] }`。
班级文件的选择题 `answer` 直接是小问数组，每关带 `identifiers`；两个版本号不能互相替换。
完整字段与示例见 [答案格式规范](AI-ANSWER-FORMAT.md)。

“只抓取已有答案”只写工作答案，不生成题目文件；它也可汇总成班级文件。
如果尚未完成的实验缺题目，先正常抓题再请 Agent 解答，不能从空的答案文件推断题意。

### 直接导入单实验 v2

主脚本支持把 Agent 写好的单实验工作答案直接导入，但身份要求更严格：

- `classroom.name`、`classroom.code` 必须完整。
- `experiment.name` 必须存在，`experiment.homework_id` 必须是大于零的真实作业号。
- `answers` 中每关都必须带 `task_identifier`，保留原始 `level_id`、标题和题型。
- 作答前，脚本会将课堂码、作业号、关卡标识与当前页面核对；数据未到、字段缺失或不一致时停止。

`L001` 只在单个实验内唯一，不能用它替代平台标识，也不能把另一个作业的身份改名后导入。
日常使用、备份和迁移仍推荐班级发布文件；单实验导入适合身份完整的局部更新。

## 3. 导入并选择作答范围

1. 打开已登录的头歌页面，刷新以加载新版脚本。
2. 点面板 **从本地加答案**。未连接控制台或连接失败时会弹文件选择框，选班级 JSON。
3. 在篡改猴菜单点 **设置签名常量（首次使用或平台更新）**，填写 AK/SK。
4. 点 **刷新课程**，选课程后点 **读取课程实验 →**。
5. 勾选实验，点 **读取关卡 →**，确认需要处理的关卡。
6. 点 **一键答题（选中）**。脚本进入对应实验，填答案并点击页面的提交 / 评测按钮。

导入会按课堂、实验和平台关卡标识建立索引，并核对答案的课堂身份。
日志中的“有答案”按可解析的非空代码或有效选择题答案计算，不依赖旧文件的 `answered` 标志。
有答案只表示存在内容，不表示内容正确或已通过平台评测；Agent 生成内容应保持 `verified: false`。

连接本地控制台是可选项。需要时在控制台点 **复制控制台连接地址**，将完整地址粘到脚本的 **连接本地控制台**。
连通后可以同步签名、加载工作答案、维护缺答案清单并回传日志；关闭控制台后，已导入的脚本答案仍保留。

## 4. 队列、停止与续跑

| 情况 | 行为 |
| --- | --- |
| 当前关已通过 | 跳过，不重复提交 |
| 未选中关卡 | 路过，推进到所选范围 |
| 缺答案、代码为空或答案与题数不符 | 记录日志并跳过；连接控制台时写入缺答案清单 |
| 提交成功并取得明确结论 | 继续下一关或下一实验 |
| 提交失败、结果不明确或评测超时 | 停队并说明当前关及原因 |
| 找不到编辑器或页面提交按钮 | 停队，保留现场日志 |
| 关卡数据未到 | 按等待设置轮询；必要时每关刷新最多两次，仍无数据则停队 |
| 用户点停止 | 停止后续提交和推进，不用旧异步任务恢复运行状态 |
| 虚拟机操作题（VNC、Notebook） | 识别后直接跳过，不上传、不评测、不上报缺答案；同环境下的选择题正常处理 |

点 **停止** 后，已发出的评测仍可能在平台后台运行；等当前处理结束后，再点 **继续答题（跳过已通过）**。
0.5.3 起，脚本保存当前关卡的标识、序号和完整地址；继续时直达中断关卡，不重新进入实验或沿链回到第一关。切换下一关前先保存目标，跳转时停止也能准确恢复。刷新后无需重选课程/实验；已通过的关卡仍会跳过。旧存档优先按现有目标、可确认属于本实验的当前关卡或首个未访问关卡定位；无法定位时保留停队状态并提示，不擅自从头走链。
想重新从头定位，可在停队后用菜单 **清空答题进度（下次从头跑）**。

评测等待优先使用页面标注的完整最大评测时长；页面没有标注时才使用面板的 **评测最多等（秒，页面读不到才用）**。
代码和选择题填写后保留 **2 秒静置**，让编辑内容同步到页面。平台另有账号共享的评测冷却，普通账号通常为评测结束后 **30 秒**，切换关卡仍有效。0.5.2 起会只读平台的冷却截止时间，等待剩余冷却结束、页面评测按钮恢复可用后才点击；不会清除冷却记录或改点“自测运行”。按钮持续不可用超过 60 秒会明确报错并停队。平台规则变化或存储不可读时，以实际按钮状态为准。

只有本次点击触发的当前关卡提交响应或评测结果响应才能确认成功；常驻“下一关／完成”按钮、旧通过结果和“已保存”提示均不推进队列。代码评测收到运行中状态会继续等待，失败或超时停队。更新油猴脚本后刷新实验页，使新的等待和网络观察逻辑生效。

**2 秒同步等待、平台冷却间隔、面板的评测结果等待上限是三个独立设置。**面板显示“评测最多等 30 秒”表示等待结果的上限，不表示已经处理两次评测间的冷却。
**关卡数据最多等（秒）** 控制页面数据加载等待，默认 60 秒。遇到网络失败会尝试刷新，不能把这一项当成评测时长。

## 5. 回捞与导出

作答与回捞只处理代码题和选择题；混合实验中的虚拟机操作关卡直接跳过，不创建后台环境任务。
0.5.6 起，按每关的选择题列表、题数或选择题结果优先判断题型，不再因为实验带 VNC/Notebook 环境就跳过选择题。从纯虚拟机关卡点击 **回捞本实验答案**，也会读取关卡链元数据、查找同实验中的其他选择题；虚拟机操作关卡不读取答案文件或发起评测。

| 按钮 | 作用 |
| --- | --- |
| **回捞本实验答案** | 读取平台可取得的标准答案或已通过代码，合并进脚本答案库，不下载文件 |
| **导出全部答案** | 将当前脚本答案库下载为班级 JSON，可再次导入 |
| **导出日志到本地** | 连接控制台时写入 `exports/logs/`；未连接时日志仍只保存在脚本中 |

回捞会按题型合并答案，保留对应的关卡身份；未通过编程题的草稿或模板不当作已通过答案。
0.5.4 起，回捞关卡数据和代码文件均通过带签名的 `data.educoder.net` 接口读取，并保留作业号和批量标记。需要登录及已配置的签名常量；HTTP 200 中的 `-102`、登录或权限错误也会明确报错，读取失败会提示本次结果不完整，不再把接口拒绝当成“实验没有答案”。
回捞需要能定位已有答案库中的关卡，因此先导入对应班级文件，再打开目标实验执行。
要备份回捞结果，需要再点 **导出全部答案**；不要把回捞后的日志提示当成已经下载文件。

纯脚本没有控制台的持久缺答案清单，**按清单再答** 需要本地控制台。
连接控制台时，通过答案可回传工作答案库；断开时，脚本在可匹配条目内保存回捞或通过的内容。

## 6. 解除禁止粘贴

完整版默认开启，面板可切换 **粘贴解锁：开 / 关**，设置会保存。
数据库系统原理的 **MySQL-数据的插入、修改与删除(Insert,Update,Delete)** 等代码实验可使用快捷键或右键粘贴。
Monaco 在当前光标或选区插入，支持多光标和撤销，并同步页面代码状态；普通文本框保留浏览器的选区与撤销行为。
不覆盖整份代码。只读编辑器、禁用输入框及任务页之外的普通区域按原页面规则处理。

若更新后仍被拦截，刷新实验页并检查开关；只需要这一项功能时可改用独立脚本，无需准备答案和签名。

## 7. 数据、搬家与排查

答案库、关卡映射、班级信息、签名、队列、面板位置与日志保存在 Tampermonkey 的 GM 存储中。
换机器前点 **导出全部答案**，新环境安装脚本并导入 JSON；AK/SK 需要重新设置，登录也需要重新完成。
面板日志最多保留 300 条，重要结果及时备份。分享答案、截图或日志前检查其中的课堂和个人信息；不要分享登录态或控制台 token。

| 日志或现象 | 处理 |
| --- | --- |
| 还没有答案库 | 用“从本地加答案”导入班级文件 |
| 签名缺失、不可用或 `-102` | 核对当前 AK/SK 的双 base64 值及登录态，平台更新后重新设置 |
| 单实验答案身份不完整 / 不一致 | 补抓当前课堂、作业和关卡，保留真实元数据，或重新导出班级文件 |
| 题数不符、答案与关卡不适配 | 回到本地运行校验与 `check-fit`，补全或修正工作答案后重新发布 |
| 数据等待及两次刷新后仍失败 | 手动检查该关是否能打开，确认网络与权限后续跑 |
| 找不到代码编辑器 / 提交按钮 | 检查页面是否加载完成，并保留日志中的现场信息 |
| 评测超时 | 先核对平台结果；需要时调大回退等待值，续跑跳过已通过关卡 |
| 面板挡住题目 | 拖动标题栏或收起；菜单“面板回到左下角”可恢复位置 |

维护脚本时，粘贴功能源码位于 `userscript/lib/paste-unlock.js`，修改后执行 `npm run build:userscripts`。
使用者直接安装生成的 `.user.js` 即可；开发校验命令见 [README](../README.md#开发与测试)。
